# Security Policy

**Status:** Draft disclosure guidance. It does not certify the security of this repository or describe a deployed security service.

## Scope and supported versions

This policy applies to security issues in code and configuration present in this repository. No formal release or supported-version matrix has been established. Do not infer that proposed architectures, third-party integrations, or deployment environments are active or covered.

## Reporting a vulnerability

Please do not publish exploit details in a public issue. If GitHub Private Vulnerability Reporting is enabled for this repository, use its **Report a vulnerability** feature. Otherwise, contact the repository maintainers through a verified private channel and include only the minimum information needed to reproduce the issue.

The project contact supplied for this repository is `contact@ssgpt6.com`; mailbox ownership and monitoring have not been independently verified. Do not send passwords, access tokens, private user data, or unrelated confidential material.

The maintainers will assess reports and coordinate any disclosure. No response time, resolution deadline, legal safe harbor, or confidentiality guarantee is offered by this draft.

## Testing boundaries

Only test systems and data that you own or have explicit authorization to assess. Do not access or modify another person's data, disrupt services, bypass access controls, or test external DNS, cloud, payment, healthcare, or emergency systems without written authorization. This repository does not establish that the proposed HNS, Cloudflare, Cloud Run, or other infrastructure exists.
