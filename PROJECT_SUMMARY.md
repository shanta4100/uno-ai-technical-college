## 📝 Content Management

### Updating Pages
Simple and straightforward:
1. Edit HTML files directly
2. Update CSS in `/css/` (or `/css/style.css`)
3. Add/modify JavaScript in `/js/`
4. Place images in `/images/`
5. Commit and push to `main`

### No Build Process Required
- Plain HTML5/CSS3/JavaScript
- Can be served by any web server
- No dependencies or build tools needed
- Works offline (download and open in browser)

## 📞 Support & Troubleshooting

### Common Issues & Solutions

**Site not updating after push?**
- Wait 2-3 minutes for deployment
- Check GitHub Actions workflow status
- Clear browser cache (Ctrl+Shift+Delete)

**Custom domain not working?**
- Verify DNS records in Cloudflare
- Wait 24-48 hours for propagation
- Check GitHub Pages settings

**Forms not submitting?**
- Enable JavaScript in browser
- Check browser console for errors
- Verify form IDs match JavaScript

**Performance issues?**
- Compress images
- Enable Cloudflare caching
- Minimize CSS/JS files
- Use PageSpeed Insights for suggestions
